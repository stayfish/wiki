# 全模态 Agent 栈：模型、工具与 Harness

## 一句话

全模态 Agent 不是一个单独模型，而是“多模态策略模型 + 工具接口 + Harness 运行时 + 受控执行环境”形成的观察—行动—反馈闭环。

## 为什么需要它

技术报告常把基础模型、插件和完整产品系统放在同一组能力展示中，容易造成两种误解：一是把外部视频生成、代码执行和持久记忆当作模型权重内部能力；二是只比较模型，而忽略工具接口和运行时对最终成功率的影响。

## 直觉

模型像负责判断和调度的导演；工具是摄影、搜索、代码和剪辑部门；Harness 是片场的任务系统，负责传递事件、控制权限、保存状态和处理失败。导演再聪明，如果看不到清晰反馈或无法可靠操作工具，也不能稳定交付作品。

## 怎么工作的

```text
用户目标
   ↓
策略模型：理解、计划、选择行动
   ↓
工具接口：把行动转换成稳定、可解析的调用
   ↓
Harness：权限、状态、并发、超时、记忆、上下文
   ↓
执行环境：浏览器、Shell、媒体工具、外部模型、真实设备
   ↓
结构化观察与错误
   └────────────→ 返回策略模型
```

### 策略模型

负责解释目标、结合当前观察选择下一动作，并判断何时停止。全模态模型还能直接利用图像、音频和视频证据，而不必全部先转换成文字。

### 工具接口

决定模型可采取哪些行动，以及参数、输出和错误如何表示。良好的 Agent-Computer Interface 会限制无关输出、提供可组合操作，并让失败原因清晰可见。多模态场景还需要按时间取片段、动态抽帧、裁剪、转码和音轨操作。

### Harness

Harness 是 Agent 的运行时，不等于推理算法。它通常负责：

- 保存事件流和任务状态；
- 把观察组装进模型上下文，并在过长时压缩；
- 执行工具调用，管理超时、重试和取消；
- 处理权限审批、沙箱和资源预算；
- 调度并行或后台子 Agent；
- 保存和检索外部长期记忆；
- 记录完整轨迹用于调试、评测和审计。

### 执行环境

真正改变外部状态的部分，例如文件系统、浏览器、代码解释器、媒体编辑器、任务管理 API、图像/视频生成器或硬件。模型说“已完成”不能替代环境验证。

## 两级检索

全模态 Agent 经常同时存在内部与外部检索：

```text
外层 Agent：决定读取哪份材料、哪个视频时间段
                      ↓
              内容进入模型上下文
                      ↓
内层 Attention/QSA：在上下文 token 中选择相关位置
```

两者不能互相替代。内部注意力无法读取尚未加载的内容；外部工具找到片段后，模型仍需在片段内部做精确关联。

## 适用条件

Agent栈适合目标无法由一次模型调用稳定完成、需要环境反馈或必须改变外部状态的任务。对于固定、可预测的流程，普通工作流通常成本更低、更容易验证，不应为了“Agent”标签强行增加自主性。

## 容易混淆的概念

- **Agent 与 workflow**：workflow 的路径主要由代码预先决定；Agent 在运行中动态选择行动。现实系统常是二者混合。
- **模型记忆与外部记忆**：模型参数和当前上下文不是持久数据库；Harness 通常将事实存储后按需检索回来。
- **原生输出与工具产物**：Thinker调用视频生成器得到视频，不等于 Thinker 自身原生解码视频 token。
- **推理与 Harness**：ReAct、规划和反思属于策略；事件流、权限、重试和沙箱属于运行时。
- **QSA 与 Agent 检索**：QSA 是网络内部上下文选择；Agent 检索是显式外部行动。

## 证据与争议

[[qwen3-8-omni]] 展示了模型、Qwen-MM-Plugins 与 Qwen-Live-Harness 的组合：模型负责多模态推理和工具意图，插件暴露视听操作，Harness 管理实时输入、异步委托、主动提醒和长期记忆。它支持这一分层框架，也暴露了能力归因问题。

SWE-agent 的 Agent-Computer Interface 和 OpenHands 的事件流架构提供了软件 Agent 侧的独立证据：相同语言模型在不同接口与运行时下可以有显著不同的任务表现。因此不能用基础模型 benchmark 直接预测完整 Agent 成功率。

## 开放问题

- 应如何用统一实验分离模型、工具接口和 Harness 的贡献？
- 何种任务应由确定性 workflow 固化，何种决策应交给模型？
- 多模态观察体积远大于文本时，Harness 应如何压缩而不丢关键证据？
- 子 Agent、长期记忆和主动监测如何获得可审计的权限边界？
