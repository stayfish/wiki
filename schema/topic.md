# 主题页模板

主题页保存到 `wiki/topics/<slug>.md`，承载跨来源比较、综述、决策框架和对话中形成的新综合。

## 默认结构

```markdown
# 主题名称

## 当前结论
## 问题范围
## 已知证据
## 主要观点或方案
## 比较与权衡
## 冲突与不确定性
## 我的判断
## 下一步阅读
## 来源与连接
```

## 写作规则

- “当前结论”可以变化，必须反映现有 Wiki，而不是最早来源。
- 比较使用一致维度，避免把不同设置下的数字直接并列下结论。
- “我的判断”记录用户在对话中确认的立场；Agent 推断应单独标注。
- 每个重要结论应能沿链接回到一个或多个来源页。
- 当主题范围过大时拆分子主题，但保留清晰的上位导航关系。
