# 开放线索模板

线索页保存到 `wiki/threads/<slug>.md`，用于尚未闭合但会影响后续阅读的问题。它不是杂乱的待办列表，而是带上下文、证据缺口和完成条件的研究问题。

## 默认结构

```markdown
# 问题

## 为什么重要
## 当前理解
## 支持证据
## 反例或冲突
## 缺少什么
## 下一步
## 何时算回答
## 来源与连接
```

## 生命周期

- 新建：已有真实问题，且现有来源不足以回答。
- 更新：新来源增加证据、改变问题或排除一种解释。
- 闭合：达到“何时算回答”的条件；在页面顶部写明结论，并连接到承载最终综合的概念或主题页。
- 搁置：说明为什么暂不继续以及恢复条件，不静默删除。

不要为一句随手问题创建线索页；只有它会指导后续阅读或反复出现时才持久化。
