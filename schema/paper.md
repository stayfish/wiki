# 论文阅读笔记模板

论文页面保存到 `wiki/sources/<slug>.md`，`type` 使用 `source`。页面不是摘要流水账，而是以后能够快速恢复“论文解决了什么、凭什么相信、和我已有认识有什么关系”的阅读记录。

## 建议额外元数据

```yaml
source_kind: paper
source_url: https://example.com/paper
source_version: arXiv v1
read_scope: full-text
status: reviewed
```

`read_scope` 可用 `full-text`、`abstract`、`excerpt` 或明确页码范围。缺失正文时不得把摘要阅读写成全文阅读。

## 默认结构

```markdown
# 论文标题

## 为什么读

用户的阅读动机、当前问题和希望特别关注的部分。

## 一句话结论

论文最重要且可核验的贡献。

## 问题与背景

作者试图解决什么，为什么已有方法不够。

## 方法直觉

先用自己的话解释机制，再补必要细节。

## 关键证据

实验设置、基线、指标和最能支持结论的结果；保留条件和数字出处。

## 局限与质疑

作者承认的局限、阅读中发现的边界、未控制变量与可复现性问题。

## 与 Wiki 的连接

它支持、修正、反驳或细化了哪些已有页面。

## 阅读后的问题

尚未解决、值得追问或需要下一来源验证的问题。

## 来源

公开链接、版本、访问日期、本地附件说明和阅读范围。
```

## 写作规则

- 区分论文声称、实验实际支持、Agent 推断和用户判断。
- 不把排行榜领先自动写成普遍优越；记录数据集、指标、工具和推理设置。
- 论文提出的新术语不一定值得独立概念页；只有跨来源复用时才拆出。
- 对代码论文，注明论文、仓库和实际检查到的代码版本是否一致。
- 对用户在对话中提出的批评，写成“用户关注”或“阅读判断”，不要归给作者。
